## How to use this

- `confident/`: validated, and corroborated or attacker-registered and current; check against your own traffic, then block. `blocking/`: validated; run in alert-only mode first. `fresh/`: the blocking domains and URLs first reported in the last 14 days, for DNS filters. `hunting/`: search logs, never block. `compromise-check/`: search DNS and proxy logs; a hit suggests an infected device. Every file expires with the release.
- `domains.txt` holds registered domains: block them with their subdomains. `hosts.txt` holds exact host names, such as one tenant on a shared platform: never widen them to the parent.
- Corroboration counts independent sources: one publisher's articles count once, and an article that links to another report counts with it. Uncited copying and joint research cannot be detected.
- Evidence, reasons and source excerpts for every indicator: `indicators.json.gz`.
- Indicators in this report are defanged. The lists are not.
